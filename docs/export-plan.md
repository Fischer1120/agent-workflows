# 导出范围与交付检查

目标是发布一个可由 agent 克隆和部署的公开仓库，保留当前协作规则及实际执行入口。

保留分层协作、任务模态限制、速度优先分流、DSH 等待规则、独立验收与纠正记录维护机制。导出全局和项目 AGENTS.md 模板、派发与适配脚本、必要的文风技能及其许可证。模型标识沿用源工作流的配置要求，实际可用性由部署机器的运行时确认。

本机账户、令牌、Bridge endpoint、模型目录快照、运行简报、私人项目历史和完整聊天记录不公开。DSH 默认模型由部署者从实时目录选择，不绑定导出机器的供应商。

实施顺序为整理可迁移目录、实现有预览和备份的安装器、验证原有派发规则和安装行为、独立审查、提交并发布到 GitHub。只修改本导出目录，原工作流保持原样。

验收需覆盖全新安装、重复安装、已有指令与纠正记录的保留、含空格路径、DSH 适配器目录生成、派发回归、公开文件扫描，以及远端仓库的可见性和提交一致性。
