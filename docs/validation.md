发布前独立审查发现并修复了下列问题，均有对应的成品或回归检查。1.1.0 档位抽象改造的独立审查另修复了 `--multimodal` 只拦 DSH 的不一致，并为本机副本补齐档位表述，两项都补了回归检查。

| 问题 | 修正 |
| --- | --- |
| 合法多行技能元数据被误拒绝 | 检查完整 frontmatter 与必要字段，保留上游原内容 |
| 脱敏切分截断记录模板 | 按章节边界提取，检查完整字段与模板内代码围栏 |
| 技能包遗漏隐藏插件元数据 | 补齐随附资源，并运行上游包校验器 |
| DSH 安装目标符号链接可导致误写 | 写前检查路径组件，拒绝目标链接，叶文件使用不跟随链接的写入方式 |
| 托管区块外同名插件冲突 | 在写入前检查区块外的重复 ID |
| 自定义 DSH 目录的验证读取默认目录 | 将所选主目录传入指令加载器 |
| 特殊字符路径的命令转义错误 | 保留 shell 字面参数，替换路径时使用回调，实际执行渲染命令验证 |
| 根安装路径的祖先链接未被拒绝 | 在路径解析前逐组件检查 |
| 合法项目同名覆盖被误判 | 分别验证共享源、原生来源及实际生效定义，并报告覆盖 |
| 清单源与目标为同文件时被截断 | 在写入前检查同路径及同 inode，包括硬链接 |
| `--multimodal` 只拒绝 DSH，低端档仍可派发（1.1.0） | 拒绝改为对所有后端生效，补 `luna` 加多模态的回归用例 |

这些检查证明所列文件和行为在本次环境中的结果，不授予目标机器模型、工具或账户权限。安装器的路径预检与写前复检不能保证抵御其他进程同时替换父目录的竞态。实际 DSH/Codex 版本和权限仍需部署者核实。
